# The expected-fail list — the executable half of wasi/COMPATIBILITY.md.
#
#   <suite>/<test>   <class>   <reason>
#
# Class is what COMPATIBILITY.md marks the row, and the three exist so that a
# defect is never quietly filed as a divergence:
#
#   divergence  the browser does not have the feature. A blank cell. Permanent
#               until the platform changes, and NOT a thing to fix.
#   gesture     real in a browser, but gated behind a user gesture no automated
#               test can supply. A game can reach it from a click; this cannot.
#   defect      the browser has it and we do not. Names its issue. THIS IS THE
#               TO-DO LIST, and it should only ever get shorter.
#
# wasi/corpus/run.sh fails if a test here PASSES: an unearned divergence is a
# lie, and a fixed defect must be struck from the list in the same change that
# fixes it. It also fails on a name here that the corpus does not have, so a
# renamed or deleted upstream test cannot hide a real failure behind a dead line.

# The four rasterisation near-misses — MEASURED (#54), and not a decision after
# all: they are upstream test-harness tolerance gates that don't know a Web
# target exists. The harness already has the knobs (rgba_tolerance,
# pixel_tolerance) and already grants them for this class of difference, gated
# on isOS('Linux'); getOS() here is "Web". Every differing shape pixel matches a
# neighbouring reference pixel EXACTLY (a fill-rule tie-break in the driver),
# and the setLineStyle delta is uniformly 3/255 in one channel of an AA blend.
# No engine change on either side converges this; the fix is upstream, in
# testing/tests/graphics.lua. When it lands these start passing and this
# witness says so.
graphics/arc	divergence	#54 — 1/1024 boundary pixel, matches a neighbour exactly; upstream pixel_tolerance=1 closes it
graphics/circle	divergence	#54 — 2/1024 boundary pixels, match neighbours exactly; upstream pixel_tolerance=1 closes it
graphics/ellipse	divergence	#54 — 1/1024 boundary pixel, matches a neighbour exactly; upstream pixel_tolerance=1 closes it
graphics/setLineStyle	divergence	#54 — AA blend 175 vs 178, max 3/255, one channel; upstream already grants rgba_tolerance on Linux, gate doesn't know "Web"
